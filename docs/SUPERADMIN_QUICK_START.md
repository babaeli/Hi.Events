# SUPERADMIN Quick Start

## Create Your First SUPERADMIN

```bash
cd backend
php artisan superadmin:create admin@yourdomain.com --first-name="Admin" --last-name="User"
```

You'll be prompted for a password.

## Create Second SUPERADMIN

```bash
php artisan superadmin:create support@yourdomain.com --first-name="Support" --last-name="Team"
```

## Login

1. Go to your Hi.Events login page
2. Use the email and password you just created
3. Access admin features through the admin panel

## What SUPERADMIN Can Do

✅ View and manage ALL accounts  
✅ Manually verify accounts  
✅ Impersonate users for support  
✅ Access system-wide statistics  
✅ Manage platform announcements  
✅ Review spam events and messages  

## Security Notes

⚠️ **Only create 1-2 SUPERADMIN accounts**  
⚠️ **Use strong passwords (8+ characters)**  
⚠️ **Never share credentials**  
⚠️ **Monitor audit logs regularly**
